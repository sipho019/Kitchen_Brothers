**Kitchen Brothers** is a modern, responsive restaurant website concept developed for a restaurant based in Mthatha, Eastern Cape, South Africa.

The project demonstrates how I combine front-end development, modern web design principles and AI-assisted development workflows to create practical digital solutions for businesses.

The website is designed to establish a professional online presence, showcase the restaurant's authentic menu and photography, and provide customers with an online ordering experience.



## 📸 Project Overview

Kitchen Brothers offers a fusion of Mexican-inspired cuisine and South African favourites.

The objective of this project is to transform the restaurant's existing brand identity and menu into a professional digital experience that makes it easier for customers to discover meals, explore prices and prepare orders online.

**Project highlights:**
- Professional restaurant branding and visual identity.
- Responsive website design.
- Digital menu with actual restaurant products and pricing.
- Interactive menu category filtering.
- Dynamic shopping cart.
- Quantity management and automatic subtotal calculations.
- Delivery and collection checkout options.
- Restaurant contact information and location integration.


## 🎯 Project Objectives

The primary objectives were to:

1. Establish a professional digital presence for Kitchen Brothers.
2. Improve the way customers access restaurant information and menus.
3. Create an attractive and user-friendly browsing experience.
4. Implement interactive ordering functionality.
5. Design a website that can be extended with a backend, database and secure online payments.
6. Demonstrate my ability to develop practical websites for real-world business requirements.

## Website Features

### 1. Professional Homepage
- Modern black-and-gold visual identity.
- Restaurant introduction and promotional messaging.
- Featured food photography.
- Navigation to important website sections.
- Clear calls to action.

### 2. Digital Restaurant Menu

The menu is organised into the following categories:

- Beef Burgers
- Chicken Burgers
- Kotas
- Wraps
- Extraaz
- Combos

Each menu item displays its name, description and price in South African Rand (ZAR).

Customers can filter products by category to find their preferred meals more easily.

### 3. Interactive Shopping Cart

The shopping cart demonstrates essential e-commerce functionality:

- Add products to the cart.
- Increase or decrease product quantities.
- Remove products.
- Automatically calculate item totals.
- Calculate the overall subtotal.
- View selected products before checkout.

### 4. Checkout Experience

The checkout interface allows customers to:

- Select collection or delivery.
- Enter their personal details.
- Provide a delivery address when applicable.
- Add special order instructions.
- Review their order summary.

**Development note:** The current checkout is a front-end demonstration. Live order submission, database storage, payment processing and restaurant notifications require additional backend integration.

### 5. Restaurant Information

The website includes:

- Restaurant contact information.
- Clickable telephone numbers.
- Location and directions.
- About Us section.
- Authentic restaurant and team photography.

### 6. Responsive Design

The website is designed to adapt to different screen sizes, including:

- Desktop computers.
- Tablets.
- Mobile phones.

Responsive layouts and mobile navigation help maintain usability across devices.

## 🤖 AI-Assisted Development Workflow

Artificial Intelligence was incorporated into the development process as a productivity and learning tool.

Rather than relying on AI to generate an entire website without understanding it, I used an iterative development approach.

### How AI supported the project

**1. Project planning**

AI assisted with breaking down the restaurant's requirements into manageable development tasks, including website structure, menu organisation, user experience and ordering functionality.

**2. Design and layout planning**

AI supported the development of visual concepts, section layouts, colour schemes and responsive design ideas.

**3. Front-end development**

AI-assisted guidance helped with HTML structure, CSS styling and JavaScript functionality.

**4. Problem-solving and debugging**

AI was used to investigate coding errors, understand JavaScript behaviour and improve implementation decisions.

**5. Learning and technical understanding**

I used AI to understand the code, explore alternative solutions and improve my ability to work independently as a developer.

**My development philosophy:**

AI is a development assistant, not a replacement for technical understanding, problem-solving or quality assurance. I use it to improve productivity while maintaining responsibility for the project's implementation, testing and final decisions.
